# Participant contributions

Create one Markdown file named after your GitHub username:

```text
participants/YOUR-USERNAME.md
```

Use this template:

```markdown
# Your name

GitHub: @YOUR-USERNAME

One useful Git habit: Write your own short sentence here.
```

Keep the contribution suitable for a public repository. Do not include an email address, access token, private path, sensitive data or unpublished research details.

Follow [Branches and pull requests](../workshop/04-branches-and-pull-requests.md) for the full exercise.
